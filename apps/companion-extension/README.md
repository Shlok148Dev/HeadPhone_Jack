# Jingle Companion (browser extension, Manifest V3)

Captures what **you** are playing in the YouTube Music, Spotify, Apple Music and Amazon Music web players you have open, and sends it only to your Jingle server's ListenBrainz-compatible endpoint. Built in Sprint 2 by extension-engineer. Install unpacked: see `docs/office/HUMAN_ACTIONS.md` HA-6.
